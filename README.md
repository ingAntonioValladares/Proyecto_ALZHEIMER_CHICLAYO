# Alzheimer: comprender para acompañar

Sitio web educativo para conocer el Alzheimer y presentar información sobre sus factores de riesgo y protectores con un enfoque claro y respetuoso.

## Contenido

- **Inicio y ¿Qué es el Alzheimer?**: explicación general, información sobre microglía y herencia, y un juego interactivo para relacionar conceptos con sus definiciones.
- **Factores de riesgo**: factores no modificables y factores modificables organizados por etapas de la vida. Cada etapa se puede desplegar para consultar sus tarjetas informativas.
- **Factores protectores**: información sobre educación, complejidad laboral, contacto social y actividades cognitivas.
- **Referencias**: las citas numeradas se pueden abrir para consultar las fuentes bibliográficas asociadas.

La navegación organiza el contenido en tres vistas: **Inicio**, **Factores de riesgo** y **Factores protectores**. El juego se puede utilizar con mouse, pantalla táctil o teclado.

## Cómo abrir el sitio

Abre `index.html` en un navegador. Si prefieres usar un servidor local, desde la carpeta del proyecto ejecuta:

```powershell
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

El proyecto utiliza HTML, CSS y JavaScript sin dependencias de paquetes. Las imágenes y videos se cargan desde las carpetas `img/` y `video/`.

## Aviso

El contenido tiene fines informativos y no sustituye el diagnóstico, tratamiento ni la orientación de profesionales de la salud.
